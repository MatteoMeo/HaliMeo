# Icona HaliMeo

Icona minimal con monogramma H, senza simbolo Wi-Fi.

- `app/src/main/res/mipmap-*/ic_launcher.png`: versione standard.
- `app/src/main/res/mipmap-*/ic_launcher_round.png`: versione rotonda.
- `HaliMeo_icon_square.png` e `HaliMeo_icon_rounded.png`: anteprime ad alta risoluzione.

Il Manifest Android è già configurato con `android:icon` e `android:roundIcon`.
In Android Studio eseguire Build > Build APK(s) per creare un APK aggiornato.
